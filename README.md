# Bibliotheks-Service

Web-Anwendung für die eigene Bibliothek, am Handy erreichbar.

## Vision

Im Buchladen scanne ich den Barcode eines Buches und sehe sofort, ob ich es schon besitze. Dazu verwalte ich, was ich ausgeliehen habe und wann es fällig ist, und pflege eine Wunschliste, die ich mit anderen teilen kann.

## Kernfunktionen

1. **Scanner:** Barcode (ISBN) scannen und prüfen: "Hab ich das schon?"
2. **Leih-Liste:** Bücher aus der Bibliothek mit Fälligkeitsdatum verwalten
3. **Wunschliste:** Bücher vormerken, z. B. für Anlässe wie Weihnachten

## Technik

Git/GitHub · PostgreSQL (Docker) · Go (Backend) · TypeScript (Frontend)
